# План: практическое введение в DevOps

## Цель

Умею развернуть приложение в облаке с CI/CD и мониторингом.

## Приёмочный тест (Definition of Done)

Финал засчитан, если на пустом аккаунте за один вечер:

1. `terraform apply` — появляется сервер, доступ только по ssh-ключу.
2. `ansible-playbook` (или манифесты в k8s) — на сервере Docker, тянет образ из registry.
3. `git push` в main — прогоняются тесты, собирается образ, тег уезжает в registry.
4. `git tag v1.0.0` — деплой на сервер, приложение отвечает `200` на `/health`.
5. Grafana показывает 4 графика (CPU, память, RPS, ошибки), при остановке контейнера в Telegram приходит алерт.
6. `terraform destroy` — всё снесено, денег не капает.

Всё описано в README так, что повторит другой человек.

## Стек

- Приложение: Python + FastAPI, счётчик визитов в Postgres, UI не нужен.
  Ручки: `/health` и `/quote` (или `/convert`), тест на 5 строк.
- Облако: Yandex Cloud, прерываемая ВМ 2 vCPU / 4 ГБ / 40 ГБ SSD, Ubuntu 24.04 LTS, зона `ru-central1-a`.
- CI/CD: GitHub Actions + GHCR. Если pull начнёт тормозить — Yandex Container Registry.
- Локально: WSL2, Docker, kind (Kubernetes).

## Режим

- Не более 3 часов в день, 6 дней в неделю, один день выходной.
- День: 30 мин теория → 2 ч руки → 30 мин заметки.
- Раз в неделю 1 ч ретро.

## Что не режем при нехватке времени

Порядок отказа сверху вниз: Kubernetes → Terraform (Ansible остаётся) → наблюдаемость до «логи + один алерт».
Не резать: Docker, CI/CD, Python.
